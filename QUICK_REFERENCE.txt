📦 PROJECT INFO
   Project ID: agridocai
   Framework: Next.js 15.3.3
   AI: Genkit 1.13.0

🚀 QUICK DEPLOY (3 Steps)
   1. ./setup-backend.sh
   2. Go to Firebase Console → App Hosting
   3. Connect GitHub repository

🔑 SET SECRETS
   firebase apphosting:secrets:set GOOGLE_API_KEY

🌐 API ENDPOINTS (once deployed)
   GET  /api/health          - Health check
   GET  /api/genkit          - List available flows
   POST /api/genkit          - Execute AI flow
